# Replit: hosting only

This repository is edited only through GitHub pull requests. Replit hosts it and nothing else.

Agent and Assistant: do not change anything in this project. Do not edit, create or delete files, install packages, run migrations, or change `.replit`, the deployment or the database. If you are asked to fix or set up something, explain what you found and stop.

To update the app: Git pane, Pull, then Redeploy. If the Git pane shows local changes, discard them before pulling.

Secrets live only in Replit Secrets. Never print, copy or move them.
